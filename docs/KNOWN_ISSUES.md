# Известные баги и недочёты

Актуальный список проблем, которые пока не исправлены.

## UI / навигация

### Заголовок пункта «Параметры» сбрасывается в «Settings»

**Симптом:** в боковом меню навигации подпись кнопки перехода в настройки отображается как «Параметры», но после выхода со страницы настроек снова становится «Settings».

**Ожидание:** стабильная локализованная подпись «Параметры» (или единый источник строки из ресурсов).

## Страница настроек

### Ломается вёрстка при вводе длинной строки подключения

**Симптом:** поле строки подключения к БД принимает длинное значение; при вводе или отображении полной строки нарушается layout страницы параметров (переполнение, смещение элементов).

**Ожидание:** многострочное поле, перенос, прокрутка или иной способ ввода длинной connection string без поломки интерфейса.

### Нельзя задать публичный ключ Supabase в UI

**Симптом:** в настройках можно изменить строку подключения к PostgreSQL, но нет полей для URL Supabase и публичного (anon) ключа; значения берутся только из `appsettings` / конфигурации при сборке.

**Ожидание:** возможность указать в интерфейсе (или сохранить локально) `Supabase:Url` и `Supabase:AnonKey` наряду со строкой подключения, без правки файлов конфигурации вручную.

### Кнопка «Выйти из аккаунта» без авторизации

**Симптом:** на странице настроек отображается действие «Выйти из аккаунта», даже если пользователь не вошёл в систему.

**Ожидание:** для неавторизованного пользователя — «Войти» (или скрытие выхода); «Выйти» — только при активной сессии.

## Диаграммы (LiveCharts)

### Тема графиков не следует за темой приложения

**Симптом:** оформление диаграмм `LiveChartsCore.SkiaSharpView` не переключается вместе с светлой/тёмной темой, выбранной в приложении; визуально график ориентируется на системную тему Windows.

**Ожидание:** цвета и фон графиков синхронизированы с темой WinUI-приложения (как остальной UI).

## Авторизация

### Нет явного оповещения при истечении сессии

**Симптом:** при истечении JWT/сессии Supabase Auth приложение не сообщает пользователю о необходимости повторного входа; запросы могут завершаться ошибкой или данные перестают обновляться без понятного объяснения.

**Заметность:** особенно на страницах администратора (управление пользователями, журнал аудита), где требуется действующая авторизованная сессия.

**Ожидание:** явное уведомление (диалог, InfoBar, переход на экран входа) при истечении или недействительности сессии.
