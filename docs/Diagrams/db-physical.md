# Физическая диаграмма БД (PostgreSQL)

Физическая модель PostgreSQL, отражающая таблицы, типы полей, PK/FK-связи и ключевые ограничения.

```mermaid
erDiagram
    faculty ||--o{ department : ""
    faculty ||--|| employee : ""
    department ||--o{ employee : ""
    department ||--o{ section : ""
    section ||--o{ employee : ""
    department ||--o{ discipline : ""
    specialty ||--o{ curriculum_item : ""
    discipline ||--o{ curriculum_item : ""

    employee {
        int id PK "GENERATED BY DEFAULT AS IDENTITY"
        text surname "NOT NULL"
        text name "NOT NULL"
        text patronymic
        text degree
        text title
        text phone
        text email
        int department_id FK
        int section_id FK
    }

    faculty {
        int id PK "GENERATED BY DEFAULT AS IDENTITY"
        text name "NOT NULL"
        int dean_id FK "NOT NULL"
    }

    department {
        int id PK "GENERATED BY DEFAULT AS IDENTITY"
        int faculty_id FK "NOT NULL"
        int head_id FK "NOT NULL"
        text name "NOT NULL"
        text phones
    }

    section {
        int id PK "GENERATED BY DEFAULT AS IDENTITY"
        int department_id FK "NOT NULL"
        text name "NOT NULL"
        int head_id FK
        text phones
    }

    specialty {
        int id PK "GENERATED BY DEFAULT AS IDENTITY"
        text code "NOT NULL"
        text name "NOT NULL"
        text qualification
        int duration
        text form_of_study
    }

    discipline {
        int id PK "GENERATED BY DEFAULT AS IDENTITY"
        int department_id FK "NOT NULL"
        text name "NOT NULL"
    }

    curriculum_item {
        int id PK "GENERATED BY DEFAULT AS IDENTITY"
        int discipline_id FK "NOT NULL"
        int specialty_id FK "NOT NULL"
        int semester "NOT NULL"
        int lecture_hours "NOT NULL DEFAULT 0"
        int lab_hours "NOT NULL DEFAULT 0"
        int usr_hours "NOT NULL DEFAULT 0"
        int practical_hours "NOT NULL DEFAULT 0"
        bool has_course_project "NOT NULL DEFAULT FALSE"
        bool is_credit "NOT NULL DEFAULT FALSE"
        bool is_exam "NOT NULL DEFAULT FALSE"
    }

    audit_log {
        long id PK "GENERATED BY DEFAULT AS IDENTITY"
        timestamptz occurred_at "NOT NULL DEFAULT now()"
        uuid actor_user_id
        text actor_display_name
        text action "CHECK IN (INSERT, UPDATE, DELETE)"
        text table_name "NOT NULL"
        text entity_id
        jsonb old_row
        jsonb new_row
    }
```

Дополнительно в физической модели используются:
- уникальный индекс `idx_curriculum_item_unique` на `(discipline_id, specialty_id, semester)`;
- RLS-политики для таблиц предметной области;
- триггеры целостности (оргструктура) и аудит-триггеры для основных таблиц.
